WooCommerce 10.9 introduces a new Color/Image product attribute type that enables visual swatches for colors and images in block theme storefronts. This brings a commonly requested feature into WooCommerce core, removing the need for third-party plugins to display visual product selectors on product pages. The new attribute type integrates with the existing variation system, allowing shoppers to pick product variants using image or color swatches.
