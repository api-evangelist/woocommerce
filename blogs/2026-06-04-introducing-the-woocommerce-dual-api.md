WooCommerce 10.9 introduces an experimental dual API infrastructure featuring an authoritative PHP code API alongside an autogenerated GraphQL interface and a development build script. The dual API approach aims to give developers two ways to interact with WooCommerce store data while keeping a single source of truth in PHP. This is an experimental feature in 10.9 intended to gather developer feedback before broader adoption.
