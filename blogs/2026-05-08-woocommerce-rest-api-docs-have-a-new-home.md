TL;DR: We’ve moved the WooCommerce REST API documentation from its standalone site to our main developer documentation at developer.woocommerce.com/docs. The docs are now smaller, faster, searchable, and optimized for both human developers and AI coding assistants. Why We Made This Change If you’ve worked with the WooCommerce REST API, you’ve probably visited our original documentation.
