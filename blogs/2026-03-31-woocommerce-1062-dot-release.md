<h2 class="wp-block-heading" id="h-what-s-in-this-release">What&#8217;s in this release</h2>



<p><strong>Adds additional fixes for variable product selection </strong>to the Add to Cart with Options block failing to work correctly when attribute names contain special characters or use custom slugs that differ from their transformed names, by comparing name-to-name instead of transformed-name-to-slug. This is a followup to an impartial fix that was <a href="https://developer.woocommerce.com/2026/03/12/woocommerce-10-6-1-dot-release/" id="8769873" type="post">included in WooCommerce 10.6.1</a>. <a href="https://github.com/woocommerce/woocommerce/pull/63771">#63771</a></p>



<p><strong>WordPress 7.0 compatibility improvements</strong> address various UI and performance issues that surfaced when running WooCommerce with the upcoming WordPress version. The updates include fixes for analytics tables and dashboard cards displaying extra padding, action buttons wrapping prematurely on smaller viewports, alignment and sizing issues across order screens, and an infinite re-render loop in the Activity panel. Additional refinements ensure proper display of metaboxes, control elements, and styling consistency across admin interface components throughout the WooCommerce admin experience. <a href="https://github.com/woocommerce/woocommerce/pull/63873">#63873</a> <a href="https://github.com/woocommerce/woocommerce/pull/63881">#63881</a> <a href="https://github.com/woocommerce/woocommerce/pull/63836">#63836</a> <a href="https://github.com/woocommerce/woocommerce/pull/63827">#63827</a> <a href="https://github.com/woocommerce/woocommerce/pull/63829">#63829</a> <a href="https://github.com/woocommerce/woocommerce/pull/63825">#63825</a></p>
